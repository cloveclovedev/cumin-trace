# 道具の要件

コマンド、サイト、ダッシュボードの要件。コマンドの名前は `cumin-trace` である。

## 位置づけ

道具は、決められたルールだけで動く。AIによる判断を含まない。同じ入力からは、いつも同じ出力になる。要件の意味を読むこと (文書の変更から要求Issueを直す提案を書く、など) は、Agentの仕事であり、この道具は行わない。

## 受け持たないこと

- 要求Issueを作らない。ラベルを替えない。GitHubには何も書かない
- 要件の間の依存を持たない。依存は、cumin-works と同じく、Issueの blocked by に書く
- サイトの公開先とアクセス制限を決めない。製品リポジトリの側で決める
