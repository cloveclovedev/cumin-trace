# 要求と要件

cumin-trace の要求と要件の文書の入口。

- [要求仕様書](overview.md): 解決したい課題、目的、位置づけ、全体の構成、決めたこと、フェーズ
- [要件文書の書式](document-format.md): IDの形、要件の欄、検証の書き方、雛形とskill
- [道具の要件](tool.md): 検査、書き出し、GitHubとの対応づけ、サイト、ダッシュボード
- [要求のbacklog](backlog.md): v0.1 には入れないと決めたが、あとで反映したいこと

## 領域の一覧

IDの接頭辞は `CTR` である。

| 領域 | 意味 | 文書 |
|---|---|---|
| `FMT` | 要件文書の書式 | [要件文書の書式](document-format.md) |
| `TPL` | 雛形とskill | [要件文書の書式](document-format.md) |
| `CHK` | 検査 | [道具の要件](tool.md) |
| `EXP` | 書き出し | [道具の要件](tool.md) |
| `TRC` | GitHubとの対応づけ | [道具の要件](tool.md) |
| `SITE` | サイト | [道具の要件](tool.md) |
| `DASH` | ダッシュボード | [道具の要件](tool.md) |
